# MES 藍色主題

助理「更多功能 → 介面外觀 → MES 藍色」新增獨立主題；原有明亮、黑暗、深藍及跟隨系統保留，預設偏好不變。繁中／英文／泰文分別顯示「MES 藍色／MES blue／สีน้ำเงิน MES」。

配色直接取自正式 MES 首頁的有效 CSS：背景 `#162a58`，漸層 `#196eae → #1a3677 → #162a58`。助理採深藍標頭與歷史側欄、藍色卡片、白色字及青藍主要按鈕。原 MES 頁面的樣式不變，版權文字保留。

主題值 `mes` 沿用現有 localStorage 偏好與同源 iframe 訊息契約；沒有第二份作業狀態、沒有新 API／套件或資料表。切換及展開不清除輸入、重建 iframe 或提交草稿，重新整理會記住主題。未送出原句跨重新整理恢復仍是既有 R06 待辦，不能以主題保存取代。
