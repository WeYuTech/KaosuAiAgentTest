新增兩項已修復問題：原 MES 查詢輪替 Token 導致嵌入身分失效（ADR 003）；模型多輪工具超過60秒時重用到期內部證明。已切換可信伺服器 Session registry，並於每次工具前重驗同一人員與模組。Spec 獨立追驗25項測試通過，未發現新缺陷。部署腳本 Standards 追驗未發現具體缺陷；主機層 ARR 變更與原 IIS 備份已明確記錄。

正式報工執行列保留原 IoT 推算 OK_QTY 時，通用前端標籤會誤稱人工良品；已在顯示層分開人工／IoT 摘要、隱藏重複原始欄位，人工明細的OK_QTY語意不變。
