# 桌面對話與作業單

使用者選定 B 版型：保留 Emerald.AI 黑白風格，左側對話、右側本次作業單，以電腦鍵盤滑鼠操作為主。三語與淺色／深色／跟隨系統保留。

## 操作與驗收

- 一個助理工作區切換排程、報工、模具上下模；保留九頁既有啟動按鈕與來源工單情境，不移除入口安裝紀錄。
- 進入作業後左右並排；左側完整對話及固定輸入框，右側作業單、資料查詢與操作紀錄。桌面驗收 1366×768、1920×1080，不另外設計平板版。
- 作業單沿用後端版本化草稿，只有一處準備／人工確認操作。移除重複的進階草稿表單與大型五步流程條。
- 按欄位編輯後，傳送自然語言前先儲存最新內容；正在修改或儲存時不得確認舊卡、切換模組。失敗保留輸入，顯示錯誤。
- 切換模組沿用可信登入權限，各自恢復草稿；未決確認卡或結果未知仍須先處理。三語、主題與重新整理保留原契約。
- 公開 HTTP 與瀏覽器驗收：報工填寫、預覽、修改、取消；排程多明細；上下模階段；桌面兩欄、鍵盤、英文及泰文換行。正式站只查詢／預覽／取消。
