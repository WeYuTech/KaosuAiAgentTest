| 面向 | 對齊結果與差異 |
|---|---|
| 資訊順序 | 目標 → 良品 → 不良明細 → 核對；精靈完整顯示選擇／填寫／核對。 |
| 閱讀寬度 | 精靈以 650px 為基準；實際內容受捲軸 gutter 影響約 635px。選取表格允許展寬。 |
| 作業單寬度 | Demo 右欄 310px，產品依可用容器約 468px；用於保留原因多列、無不良選項、錯誤及三語文字。未改外殼或側欄結構。 |
| 分組／文字層級 | 19px 主標題、約 14px 欄位、40px 控制；目標只集中一處，原聊天訊息完整保留。 |
| 不良資料 | Demo 一個數量與原因；產品保留未回答／無不良的區別、多列原因、合計及選填備註。 |
| 主要動作 | 基本報工在 1366×768 預設側欄下，目標、良品、原因／數量及核對同時可見；核對期限與同意按鈕保持同一固定列。 |
| 核對 | 標籤／值列、一個主要標題；未改變的值不畫刪除線。產品另保留 IoT 說明、版本／期限、技術明細及真實異動。 |
| 返回 | 返回修改不取消原 proposal；不改值再次核對不重新 prepare。相同 execution 重選不清數量，換另一 execution 才清數量。 |
| 結果 | Demo 為本機假回執；產品使用隔離 HTTP transaction／audit 實際成功結果。兩者分開標示。 |
| 字體 | 保留專案字體及作業系統繁中字型回退；未為逐像素比較引入字體套件。 |
