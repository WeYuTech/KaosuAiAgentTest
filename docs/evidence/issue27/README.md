### 實際瀏覽器操作（隔離環境）

使用正式 build、真實 HTTP 與隔離 SQLite 業務模擬，瀏覽器預覽關閉付費模型。不是固定回覆 Demo。

1. 首頁輸入「你能幫我做什麼？」、選模擬身分後保留原文；真正送出後顯示模型未設定與有權限的三入口。
2. 新增報工：MC37 → WO-A／EPS-A／08:10 執行紀錄 → 良品 120、缺料 2 → 切精靈 → 良品 125 → 伺服器核對 → 切回作業單 → 唯一確認 → 隔離寫入成功。重新從歷史讀回 125／2 與已完成狀態。
3. 排程新增：MC36、EPS-A、MOLD-A；第一模具明細 WO-A／2 穴，第二明細 EPS-B／未分配 0 穴；開始 2026-10-30 18:00、週期 60、目標 100，實際預覽結束 19:40、第一列 200 件，取消未寫入。
4. 模具：開始上模 → 明確選 MC36 排程 → 直接到伺服器核對，無空填寫頁；切精靈與重新整理從歷史恢復同一卡，320 像素以鍵盤到達確認控制，再取消。
5. 已完成報工 → 繼續此工單 → 修改報工 → 就地選單筆 125／2 → 帶回既有良品、不良原因與數量 → 切精靈 → 真實修改預覽。沒有確認寫入第二次業務變更。
6. 1366×768、1920×1080、768×1024、390×844、320×700：讀取實際 viewport、DPR、工作區及表單 rect；測到的畫面無頁面水平溢出。繁中、英文、泰文及淺色、深色、深藍、MES 藍色均有操作，跟隨系統在最初淺色環境使用；未測作業系統主題動態變更。
