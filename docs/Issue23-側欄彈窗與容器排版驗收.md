# Issue #23：側欄、彈窗與容器排版實作驗收

## 本輪狀態與邊界

承接 [Issue #23](https://github.com/WeYuTech/KaosuAiAgentTest/issues/23)，以 PR #22 的 `c60a18ab7bdfa73ef0328bb8335dad7d051b9e04` 為固定基準，分支為 `codex/issue23-sidebar-layout`。#22 尚未合併，因此本 PR 疊在 `codex/issue21-motion-feedback`，不是從舊 main 重做。

本輪提交正式 React 的側欄、共用彈窗、管理表單及業務卡改版。**產品程式可審查，但完整視覺／無障礙矩陣仍有未執行項目；不關閉 #23、#21、#19 或 #13，不自動合併或部署。** 正式站仍以既有部署紀錄的 `387dcf0` 為準，本輪未修改正式站。

不新增套件、不修改 API 或 DB Schema，不改變 Guide、proposal、權限、確認與 unknown 契約。所有操作都在本機隔離模擬資料進行；模型金鑰為空、測試額度設為 0，本輪無真實模型呼叫。正式 US$20 累計帳本沒有重設或變更。

## 實作

- 側欄頂端為緊湊 WeYu、搜尋、收合；當前布局只有一個新聊天入口。聊天／封存／已刪除使用固定下拉選單，保留既有排序、分頁及伺服器搜尋。長標題單行省略，完整名稱仍可取得。
- 搜尋明確開啟、關閉；關閉清除條件、回第一頁並聚焦搜尋圖示。命名／刪除後原列若被刷新移除，焦點回到可見搜尋控制，不再嘗試聚焦隱藏輸入框。
- `SidebarSplitter` 使用 Pointer Events、capture、單一 RAF；放手才保存，取消／Escape／失焦／卸載清理。預設 288、最小 240、最大 420 CSS px，動態上限扣除 24px 操作區與至少 480px 主區。小於 900px 的容器使用抽屜。
- 分離外框大小、側欄偏好、暫時可用寬度及抽屜開關。方向鍵 8px、Shift 32px、Home／End、Enter 收合、雙擊重設；範圍選單另有加寬／縮窄／重設。ARIA 提供 separator、controls 與數值。
- `OperationDialog` 共用可見標題、關閉、捲動正文及操作列；管理確認使用實際動詞與對象。僅顯示已變更設定，保留原送出契約。組字 Escape 不關窗。
- 原始 Dialog 的 `w-full`、`sm:max-w-lg`、`p-6` 與管理 CSS 衝突，新增可選 `operation` 布局模式，定位、Portal、Radix 焦點與動態仍沿用來源；布局由 `management.css` 單獨負責，不疊高權重補丁。
- 費用摘要與統計分區，直接呈現既有已用／預留／上限／剩餘資料，不重算未知金額。定時報告依自身容器切換一／兩欄，主要動作為查看，暫停／恢復／刪除收入選單。
- 候選卡分層顯示設備工單、模具時間階段；保留模具明細與下一階段。報工、排程表單及摘要依自身容器重排。數量與單位成組，資料／稽核首層使用可辨識摘要。
- 核對步驟保留進度及返回修改，移除重複狀態與相同標題；成功技術識別預設收合，unknown 仍保留原識別與查核。摘要維持唯讀，沒有增加第二個確認來源。
- `motion.css` 回歸動態責任；側欄、管理布局與業務容器分別由 `history.css`、`management.css`、`operation-layout.css` 管理。保留已移除的重新讀取與聊天筆數，不恢復休眠功能。

鍵盤分隔線語意參考 [WAI-ARIA Window Splitter](https://www.w3.org/WAI/ARIA/apg/patterns/windowsplitter/)，不等於已完成真實讀屏驗收。
