## 第 1 輪修正與新增發現

- 返回按鈕與 `backToEdit` 共用 `hasEditableFields`：有欄位為「返回修改」，無欄位為「返回選擇」。核對與拒絕狀態均適用；無欄位返回時明確開啟既有對象選取彈窗，避免只改步驟卻留下空白作業區。
- B09 依審查裁定補正範例兩處獨立確認條件，重建 HTML 並重拍兩尺寸標準圖。參考修正獨立 commit：`744e370`，未更改產品獨立確認卡控。
- 新增共用 `tests/manual/visible-text.cjs`：按標題、狀態、內容、步驟與動作分組，讀取實際可見文字與控制項值／空值提示。排除未展開明細與讀屏專用文字，只正規化空白換行，不改寫標籤、數值或按鈕。每組原文及一致判定存入 `量測.json`；不同 DOM 的純包裝分段不算差異。
- 新文字檢查另抓到排程摘要缺品名、狀態缺代碼、未分配工單缺提示，已用既有主檔與欄位值補齊，未新增業務資料。
- [返回按鈕實際驗收](返回按鈕驗收.json)：待確認／已拒絕 × 修改、刪除、完工、下模完成、清除，10 組皆檢查按鈕文字與返回目的地，沒有呼叫提交 API。單元測試另涵蓋四個模具階段與全部可編輯動作。
