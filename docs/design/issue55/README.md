## 量測與可重現性

- 原始四軸座標及新增彈窗／最新內容檢查：[量測 JSON](量測.json)。
- 六項計算值的原始證據：[樣式 JSON](計算樣式比對.json)。表格依相同值分組，但 JSON 保留每個畫面與每一列；不把別名字型、近似色彩或行高正規化成一致。
- 元件包含標題、內文、側欄項目、按鈕、輸入框、彈窗標題，另測說明、列表列、動作與最新內容。#44／#47 為範例沒有的保留功能，不虛構其對應樣式。
- 範例原有 PNG 實際是 1366×744／406×810；本輪重新開啟原 `reference.html`，只移除範例控制列及宿主留白，將外框設成 1366×768／390×810。範例內部 CSS 與標準圖片未被修改。
- Windows Chromium 的 LCD／圖層反鋸齒曾使相同字型、計算值及位置的文字整片標紅。已用平台字型檢查確認兩邊正文均使用本機 Noto Sans TC；本輪兩邊統一以 `--disable-lcd-text` 擷取灰階反鋸齒畫面。這是驗收瀏覽器設定，不注入正式程式，不遮罩或刪除差異像素。上一輪影像仍保留在 Git 的 `b14c7df`。
- C02 是 HTTP fixture 注入的長 Markdown 訊息呈現，不當作真的從 MES 查詢成功的證據。fixture 全部位於 `tests/manual/`，不進產品包。

重建方式（倉庫根目錄，先到 frontend 執行 `npm.cmd run build`）：

```powershell
node tests/manual/issue55-capture.cjs
node tests/manual/issue55-style-report.cjs
node tests/manual/issue55-environment.cjs
node tests/manual/issue55-record.cjs
node tests/manual/issue55-video-check.cjs
```

使用既有無頭 Playwright／Chromium 與 FFmpeg，未新增套件。每次建立獨立記憶體 fixture、loopback 伺服器與瀏覽器，在 finally 關閉。證據不含正式登入、金鑰或 session。
