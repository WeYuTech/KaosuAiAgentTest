## 重現方式

先建置前端，再依序執行 `node tests/manual/issue58-capture.cjs`、`node tests/manual/issue58-report.cjs`、`node tests/manual/issue58-safety.cjs`。影片使用 `issue58-record.cjs`，實播檢查使用 `issue58-video-check.cjs`。回歸使用 `issue58-regression.cjs`，預設第三段；環境變數 `STAGE=2` 執行第二段。

所有 fixture 位於 `tests/manual/`，使用隨機 loopback 連接埠與無頭 Chromium；腳本 finally 關閉瀏覽器及測試伺服器。截圖固定連續動畫相位以免旋轉角度污染幾何量測；正常速度錄影及安全測試不暫停動畫，實際驗證 850ms／linear，reduced-motion 停止旋轉並保留狀態文字。
