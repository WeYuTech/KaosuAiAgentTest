## 保留的限制與修正過程

- 第一輪 30／30 未含輸入框，第二輪加入後為 14／30；本輪取得裁定並修正後才重新標示 94／94。歷史失敗保留在 Git，不沿用舊結論。

- 初次恢復完整窄版訊息後，實際看圖發現舊網格 important 仍將對話推到底部；已移除衝突並重新跑三段，不以只通過輸入框量測交付。
