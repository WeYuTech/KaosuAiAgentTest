## 既有 API 盤點

| 介面 | 實際欄位與限制 | 本輪處理 |
|---|---|---|
| 聊天清單 | `q`、`scope`、`page`、`page_size`；依本人及模組權限查詢，釘選優先、更新時間排序 | 固定釘選／近期分組，獨立搜尋彈窗，保留錯誤與重試條件 |
| 聊天 metadata | 必須帶 `version`；可改標題、釘選、封存、刪除旗標；標題去空白後不可為空、最多 100 字 | 命名失敗保留輸入，刪除確認說明不影響 MES；還原保留原旗標 |
| 管理讀取 | 設定版本、模型清單、推理強度、工具輪數、帳本、硬上限、可寫權限、金鑰已設定布林值 | 一般使用者只有文字資料；不顯示金鑰片段或虛構更新時間 |
| 管理儲存 | 主管權限；整份設定及版本；409 衝突、403 權限錯誤；工具輪數 1–5 | 先核對真實原值與新值；未修改不能送出，失敗保留核對內容 |
| 用量儲存 | 上限不得超過部署值與 US$20；提醒比例 1–100%；不得清除既有帳本 | 表單限制與後端檢核並存；使用原累計帳本 |
| 報告 preview | 只接受 `{text}`；每天／週一至週五、單一模組、24 小時制時間；設備解析只接受 MC 編號 | 表單轉為明確條件文字，核對解析結果與原表單完全一致後才允許建立；不符時阻擋並說明 |
| 報告建立 | 名稱、模組、設備、頻率、時分、`client_id`；本人授權模組、最多 20 份；相同 client ID 保護重試 | 表單直接填寫，句子解析為選用；核對後建立，重試保留識別 |
| 報告變更 | 僅支援版本及 active／paused／deleted；不支援編輯既有條件 | 提供暫停、恢復、刪除確認，不增加編輯功能 |
| 報告歷史 | running／completed／failed／missed／interrupted；刪除後資料仍留存，清單不再列出已刪除報告 | 各狀態用業務文字，未完成不當成零產出；刪除警語如實說明 |

### 契約差異

既有報告預覽是有限文字解析，無法預覽非 MC 編號的設備條件。本輪明確拒絕不一致的解析，不將該條件悄悄改成「全部設備」。後端唯讀定時報告不呼叫模型，沒有「額度超限」執行狀態；超過單次查詢範圍等錯誤會被後端統一記為 failed。本輪如實顯示查詢未完成，不虛構額度狀態，也不更動後端規則。

## 可重現驗收

先用既有命令建置前端。設定 `PLAYWRIGHT_CORE_PATH` 可覆寫本機既有 `playwright-core` 路徑，`CHROMIUM_PATH` 可覆寫擷取用後備瀏覽器路徑，播放驗證使用 `BROWSER_PATH`，編碼器使用 `FFMPEG_PATH`；不需新增套件。每次 capture 都建立新的 fixture DB 與獨立 fixture 用量帳本，若 DB 已存在則拒絕啟動。分類、模型回覆與報告執行紀錄均為模擬，禁止將此證據解讀為正式 MES 寫入或真實模型驗收。

node tests/manual/issue34_capture.cjs 390
