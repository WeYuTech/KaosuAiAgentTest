## R01–R06 的實作與證據界線

| 項目 | 本輪變更 | 驗收狀態 |
|---|---|---|
| R01 無模型人工起步 | 文字仍可編輯；提供明確清除文字後接人工卡片的入口；送出模型按鈕保持停用 | 已實作；U01／U02 的新版瀏覽器操作未執行，不標完整完成 |
| R02 身分隔離 | 清除 audit、feedback、草稿投影、問題面板及記憶；請求及恢復結果均核對情境版本；404 另查 session，403 不降級建立新對話；保留原 actor 恢復標記 | 請求與實際恢復 helper 組合 8 項通過；完整換人 UI／晚到各面板回覆仍待瀏覽器驗收 |
| R03 明確拒絕後恢復 | 4xx 先記錄 `rejected-unverified`；權威讀回原卡才開放修改／取消，舊卡不能同意；其他未知嘗試不被清除 | 新增 409→讀取失敗→讀回 pending 回歸通過；原 unknown 回歸通過，畫面待驗 |
| R04 跨分頁原操作 | 阻擋 B 提交時可定位 A。切換前先 flush B；另提供「保留本頁，只查核原操作」，B 含 invalid 或保存失敗時也可唯讀查核 A，不覆蓋 B 草稿 | 恢復標記及零 B 提交函式測試通過；雙分頁完整 UI／dirty／invalid 路徑未執行 |
| R05 摘要缺項定位 | 顯示後端缺項、目前階段與保存狀態；點缺項先收覆蓋面板再聚焦主欄位。摘要不重複同時列 proposal 與完整草稿 | 已實作；焦點、窄版、三語實際瀏覽器未執行 |
| R06 首次原句一次接續 | 選模組及可信身分後，模型可用且無待核對操作才接續原句；同步鎖防雙點，無模型保留人工入口 | **部分實作，U15 重載仍不通過設計檢查**：未送／失敗原句目前僅在 React 記憶體，尚未做受身分／範圍約束的持久恢復。不得宣稱 R06 完成 |

R06 剩餘工作：加入受可信 actor 與 scope 約束的首次文字保存；重新載入後只恢復可見文字、人工決定重試，不自動重送已嘗試訊息。必須驗證建立失敗、模型失敗、重載、換人、換 scope、unknown 等分支；持續追蹤 Issue #13，不以本輪 UI PR 關閉。
