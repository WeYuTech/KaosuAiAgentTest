# 三語步驟引導增量規格

狀態：使用者已核准本輪計畫，實作與約定驗收已完成。本文件補充既有 [實作規格](實作規格.md)，不取代原排程、報工、上下模卡控及確認契約。文件、工作項目與提交訊息使用繁體中文；使用者本輪明確要求介面支援英文、泰文，故這兩種介面翻譯屬已授權範圍。

工作追蹤：[GitHub Issue #9](https://github.com/WeYuTech/KaosuAiAgentTest/issues/9)。前置需求為已完成的原三模組、可信登入與確認交易（Issues #1–#7）；本輪分為下列三個切片，不自動合併程式變更。

## 使用者流程

五步固定為「選作業 → 選設備／工單 → 補齊資料 → 核對並確認 → 查看結果」。人員可依引導選取，也可直接以自然語言說出完整需求；已提供的資料不應要求重填，只追問缺少或有歧義的內容。原三模組全部操作保留，不以精簡流程刪除排程修改、報工刪除、模穴、完工、上下模四階段或清除。

| 步驟 | 可驗收行為 |
|---|---|
| 選作業 | 選擇排程、報工或模具上下模及對應動作；沿用可信登入，選項不提升權限；小窗選完模組後放大 |
| 選設備／工單 | 沿用宿主頁面線索並查詢核對；多筆工單、排程或模具明細須明確選擇，不能猜第一筆 |
| 補齊資料 | 自然語言與選項共同補齊草稿，保留已知值；三個模組使用既有工具與後端卡控 |
| 核對並確認 | 顯示設備、工單、模具明細、數量、時間與連動範圍，資料版本及摘要雜湊綁定；只有人員明確確認可寫入 |
| 查看結果 | 顯示可證明的成功、取消、拒絕或結果未知；未知僅查核原操作，不自動重送；人工與 IoT 推算分開 |

## 語言與主題

- 語言為繁體中文 `zh-TW`、英文 `en`、泰文 `th`，預設繁體中文，記住瀏覽器選擇。切換影響介面及後續 AI 回覆；歷史訊息保留原文。
- 工單、設備、品號、模具識別、操作人員與備註保留來源原值，不為翻譯改寫業務內容。語言切換不建立新操作、不使既有確認卡內容或 digest 改變，也不替人員同意。
- 主題為淺色、深色、跟隨系統 `light/dark/system`，預設跟隨系統，記住瀏覽器選擇。沿用 Emerald 品牌與原黑白設計，支援電腦及觸控平板。
- 主要文字至少 16px，主要操作按鈕至少 48px 高；放大、收合、捲動與焦點均可操作，不遮住確認內容。
- RAG 在既有已審核知識中支援跨語檢索；不讓使用者輸入或翻譯內容直接成為已發布知識。回饋仍須審核及候選案例回歸。

## 介面及後端契約

前端以 `Accept-Language` 表達選定語言，新對話保存 `locale`。既有對話的語言變更使用受身分檢查的 locale 更新介面；修改語言不重建對話、不改歷史原文、操作草稿及確認摘要。後端須限制語言白名單，模型僅依選定語言產生後續說明，受限工具、可信身分與交易邊界維持不變。確切 HTTP 欄位以最終 OpenAPI 及公開邊界測試為準。

首頁 `wwwroot/index.html` 加入入口，與既有八個 MES 作業頁共九頁。新安裝仍採 `schema: 1` 備份清單，還原接受原完整八頁或新完整九頁；不接受任意缺頁、重複頁面或額外路徑。從既有八頁升級時只修改尚未安裝的首頁，保留原八頁位元組及原備份；新備份還原只撤回本次新增內容。

不新增正式業務資料表。AI 專用資料仍遵循 `ZZ_AI_AGENT_OPERATION_` 命名；真實業務操作仍須可信登入、授權、狀態重驗及人員確認。確認結果未知時不可因換語言、換主題、上一頁或重新整理而重新寫入。
