## 真實模型與預算

`scripts/evaluate_trilingual.py` 透過公開 HTTP 呼叫真實模型，三種語言各依序驗證：查詢 MC37 人工與 IoT 數量、數量未齊時補問、人工良品 20 且無不良時產生確認卡、改為 18 時取代舊卡。每步核對業務快照未變；前兩步不得產卡，後兩步核對目標、數量、舊卡失效及持久化引導。切換語言後確認摘要 digest 不變，最後取消卡片。

第一次 12 階段的功能檢查通過，但檢視正常回答時發現內部識別碼外露。已修正模型指示；第二次增加禁止正常回答包含測試內部識別 `2001`／`1001` 的斷言，12 階段再次通過。識別仍可由受限工具在後端核對，不能要求現場人員理解資料庫 SID。

最終原始證據保留於本機受控 `.local/trilingual-evaluation-final.json`，不將整份對話／操作快照加入 Git。已核對 `passed=true`、`mode=simulation`、`source_business_writes=0`，繁中／英文／泰文各四筆 HTTP 200。帳本累計 **171 次呼叫、US$1.110602**，未知呼叫 **0**、未結算預留 **0**；此數字包含此前驗收，不是本輪單獨費用。原 **US$20** 上限保留，帳本在後端主機，開發機額度保持 0，不重設或分機重複使用額度。
