## 正式應用對照與必要適配

| 參考設計 | Kaosu 正式實作 |
|---|---|
| Zinc 黑白、淺灰與深色語意 | `emerald-design-tokens.css` 沿用色彩與字級；表單邊界／焦點加深以便辨識 |
| 圓形 44px 入口、精簡浮窗 | `desktop.css` 與 MES `widget-loader.js` 同步；桌面上限 450×562.5，距右 16px／底 76px；窄螢幕全畫面 |
| 品牌標頭、圖示工具 | `AssistantHeader`；放大、操作紀錄、語言／外觀選單、收合 |
| 歡迎文字、輸入框、直排建議 | 起始畫面先說需求，再選三種有權限的作業；不靠文字自稱取得身分 |
| 展開後左側導覽 | `OperationSidebar` 顯示三模組與本次作業／操作紀錄；後端沒有對話清單 API，因此不假造對話搜尋、重新命名或刪除 |
| 純文字助理、灰色人員訊息 | 助理移除多餘頭像與卡片背景；使用者保留純文字灰色圓角訊息；資料卡及確認卡保留結構 |
| 圓角 composer、圓形送出 | `ConversationComposer`；輸入框自動高度，Enter 送出，Shift+Enter 換行，輸入法候選確認不送出 |
| 閱讀歷史不中斷 | 人員捲離底部時不因訊息更新強迫跳回；提供「查看最新內容」 |
| 48rem 對話閱讀寬度 | 限制訊息欄的閱讀寬度，整個展開工作區仍滿版；唯讀摘要按需側開／窄版覆蓋 |

保留繁中、英文、泰文、跟隨系統、離線字型、既有原始資料值與 MES UTC+07:00。移植的是視覺與元件布局，沒有新增 `@assistant-ui/react`、Radix、Tailwind 或另一套聊天狀態管理。來源既有黑白品牌 SVG 與 Inter 字型沿用專案已追蹤資產。

收合助理改為隱藏同一個 React 子樹，保留 Guide 編輯值與已展開狀態；重新開啟不建立新對話。MES iframe 收合後維持同一個 frame，重新開啟由原助理回報尺寸。按鈕和自然語言仍共用既有 Guide、proposal 與 API；人工確認仍只有原來的有效入口。
