# ADR 007：以分段輪詢取代 SSE 傳輸

日期：2026-11-03。關聯 #47；取代 ADR 006 的 SSE 傳輸與 IIS 全域緩衝決策，保留業務、停止與費用契約。

正式 ARR 在完整處理結束後才交付 SSE，調整 responseBufferLimit 並未通過驗收。改用一般 JSON：首頁與對話的 `/messages/start` 立即回傳 request_id、token；`GET /api/streams/{rid}/events?after=seq` 最多等待一秒，取得新事件即結束回應。輪詢需要可信登入者與 X-Stream-Token，禁止快取。原 `/messages` JSON API 保留，移除 `/messages/stream`。

事件依序號保存在單一程序記憶體（部署前提 workers=1），非破壞性讀取，不因斷線清空。終態後保留五分鐘，之後清除記憶體及既有 STATE 暫存列；步驟摘要仍隨對話保存。停止權杖在終態從持久化狀態移除，記憶體讀取憑證只存活到保留期結束。服務重啟後不保證事件接續，必須查核原操作，不能重送。

前端僅重試冪等 GET，不重送 POST，不用計時器產生文字。停止仍走原端點：唯讀中止上游，寫入類只停止等待。費用帳本、工具呼叫、人工確認與版本檢核不變。

IIS 安裝腳本不再修改 responseBufferLimit；不要求追加任何全域緩衝設定。本應用的動態壓縮停用保留。驗收透過收齊完整回應才轉送的隔離代理，正式 IIS 未部署亦未驗收。
