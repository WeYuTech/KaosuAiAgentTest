# ADR 005：雙流程共用草稿與唯讀意圖版本

日期：2026-11-02。狀態：已實作、驗收範圍見 Issue #27 報告；尚未部署。

## 依據與相容範圍

Issue #27 以 PR #26 的 `b27a34e253a612bb90464ad9d7184e9f3345c1b4` 為開發基準，外觀參考固定於 `3e78775de18fad1eaf82a4d783ba5712bdd541d0`。本決策更新舊規格中強制先選模組、摘要只能唯讀、任何訊息一律作廢確認卡及每個動作固定三步的限制；原業務權限、資料狀態、交易及確認規則不變。

## 單一作業、兩種呈現

既有 React `GuidedFlow` 保持同一個 conversation key、草稿、保存佇列與 proposal。聊天＋作業單以左右工作區呈現；精靈依目標、內容、核對呈現，沒有欄位的動作略過內容步驟。摘要／資料檢視不能建立另一個確認來源。

偏好以 `mes-operation-view:v1:` 存在瀏覽器，依 actor 與環境隔離。切換不 flush、不送 Guide、不建立預覽。保存、模型、查詢、確認與輸入法組字期間暫緩套用，完成後採最後選擇；dirty 本身不構成切換障礙。其他分頁不監聽偏好變更。損壞或不可用儲存降級至預設／當頁記憶，不放寬提交恢復保護。

## 未綁模組入口

- `POST /api/entry/messages` 接受入口識別、請求識別、原文、語言與宿主 context；可選模組僅代表使用者選擇，仍須授權。
- `GET /api/entry/{id}` 恢復該 actor 的中立聊天；`GET /api/entry/requests/{id}` 查核原請求，未知不重送。
- 紀錄使用既有 `STATE` JSON 列，命名空間為 `entry:v1:`、`entry-request:v1:`。不增加資料表或欄位。
- 同一請求識別只能對應同一原文、入口與模組選擇。分類先取期限租約，交接與 conversation 登錄於同一交易完成；逾時查核撤銷舊 token，晚到分類不能恢復租約或建立第二份工作。
- 真實 Responses 分類器只回能力／唯讀／變更／澄清／不支援與模組枚舉，不具有工具或授權。無模型時如實顯示可用人工流程。
- 自動交接保留原文一次；人工捷徑可透過原 `POST /api/conversations` 的可選 `entry_id` 接續已送出的聊天，不偷偷重送原句。舊客戶端不傳此欄位仍沿用原契約。
- 有 pending／unknown 時回到原操作確認、取消或查核。手動交接同一入口具冪等性，跨 actor 不可讀取。

## 聊天與業務版本分離

接收訊息只追加聊天並取得 processing lease。分類中 confirm 在伺服器端拒絕，包含另一分頁／另一應用實例。明確變更才增加業務 revision 並 supersede pending；Guide 的實質保存仍增加版本與 revision。混合說明與變更應分類為變更，不確定先澄清。

唯讀路徑只註冊查詢及已發布知識工具，傳入目前草稿供說明；不提供 update／prepare callback。實際返回的工具名稱必須仍在白名單，返回 action／proposal 也會被 handler 拒絕。每次工具前及回覆保存前重新驗證身分。唯讀回覆取最新 Guide／proposal，不恢復歷史 pending。模型或分類失敗只清除相同 token 的 lease；unknown 仍只能查核原操作。

既有 proposal 的 revision、digest、到期時間、環境、操作者及資料狀態檢核全部保留，不遷移或延長舊卡。

## 有界候選查詢

`GET /api/candidates` 僅供有排程權限者查設備、品號、模具及工單。`kind` 固定白名單；搜尋編號／名稱使用 contains，工單及模具先限品號。頁碼 1–500、每頁 1–100；固定來源、參數化條件、固定識別排序，取得一筆額外資料判定 has_more。回傳 filters、page、page_size、has_more、truncated，total 為 null，避免把本頁筆數當全資料總量。

目標執行／排程仍沿用原 `/api/workspace` 的條件、範圍上限及權限。新增候選 API 未提供給模型當任意 SQL 工具。實際 SQL Server 執行計畫及全廠延遲尚未量測，不能以模擬 250 筆結果推論正式效能。

## 代價

分類新增一次有預算追蹤的模型請求；唯讀／變更仍共用現有 Responses 及管理模型設定。中立入口紀錄沿用 JSON 儲存，尚無自動清理策略。完整驗收、來源對照及未執行項目見 [Issue #27 驗收](../evidence/issue27/README.md)。
